Question 1 : L'algorithme de la puissance itérée renvoie un vecteur propre, qui peut dans notre cas représenter pour chaque page (car la longueur du vecteur propre sera égal à la taille de la matrice) son score, une valeur du vecteur propre sera plus ou moins élevée par rapport à ses 1 et 0 dans la matrice, représentant les degrès entrants et sortant (car nous multiplions les matrices à chaque fois les lignes par les colonnes) et dans la définition de la création des scores du page Rank, les pages pointées par beaucoup de pages reçoivent plus de point. Il est aussi important de souligner qu'en rendant la matrice stochastique (ce qui est facilement faisable ici grâce au fait que la matrice du Page Rank n'aie que des 0 ou 1) on pourra facilement simplifier l'algorithme et terminer par un vecteur convergent vers la valeur propre 1, grâce à l'application de la norme du vecteur normal, ce qui facilite les études des scores. On peut alors simplifier l'équation par Xn+1 = AXn, qui se rapproche de l'équation qui nous a été donné dans cette SAE : r = Qr.

def norme(X) : #Renvoie la norme qui est egal a la racine de la somme des valeurs du vecteur au carré
    return np.sqrt(np.sum(X**2))

def puissanceIteree (A,e,Xo,incr) : #L'algorithme du cours qui va nous permettre d'obtenir le tableau des scores
    Xn = Xo.copy()
    XnOld = np.zeros(len(A))
    #Pour complètement implémenter l'algorithme, on doit séparer le cas si la matrice est stochastique ou non,
    #mais on utilisera ici seulement le cas ou la matrice est stochastique
    if (estStochastique(A)) :
        while (norme(Xn - XnOld) > e) :
            XnOld = Xn.copy()
            AXn = A.dot(Xn)
            Xn = AXn.copy()

        while (norme(Xn - XnOld) > e) :
            XnOld = Xn.copy()
            AXn = A.dot(Xn)

def creerClassement(Xn,i) : #Créé le classement sous la forme (numéro de la page,score) grâce à un tableau de tuples
    T = []
    for j in range (i,len(Xn) + i) :
        T.append((j,Xn[j - i]))
    return sorted(T, key= lambda x : x[1],reverse = True)

def stochastique(A) : #Créé la version stochastique de la matrice en paramètre (primordial pour cette SAE)
    M = A.copy()
    for i in range (len(A)):
        temp = 0
        for j in range (len(A)) :
            if (A[j][i] == 1.0) :
                temp += 1
        for k in range (len(A)) :
            if (A[k][i] == 1.0) :
                M[k][i] /= temp
    return M

def estStochastique(A) : #Renvoie si la matrice en paramètre est stochastique ou non
    for i in range (A.shape[0]):
        temp = 0
        for j in range (A.shape[0]) :
            temp += A[j][i]
        if (temp != 1.0):
            return False
    return True

def transposee(A) : #Retourne la transposée de la matrice, ici elle va servir à transformer nos matrices à la base qui sont des matrices du web
    return A.T      #En matrice de Page Rank, pouvant alors être étudiée


def solutionEquation(V,W) : #Renvoie la norme de la différence des deux vecteurs, servant à se retouver avec une seule valeur à étudier                          #pour étudier les comparaisons
    return norme(V - W)

def verification(Q,e) : #Vérifie si la matrice trouvée résout l'équation r = Q*r

    else :

Cela est logique car en augmentant la valeur du critère d'arrêt, le vecteur aura à faire moins de divisions, ce qui amène à se retouver avec une norme plus grande, et inversement.

def classement(R) : 
    nbAbos = []
    for i in range (len(R)) :
        cpt = 0
        for j in range (len(R)) :
            if R[j][i] > 0 :
                cpt += 1.0
        nbAbos.append((i,cpt))
    nbAbos = sorted(nbAbos, key= lambda x : x[1],reverse = True)
    return nbAbos
